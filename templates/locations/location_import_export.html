Daten importieren

Importieren Sie Lagerorte aus CSV-Dateien. Laden Sie zuerst die Vorlage herunter und füllen Sie diese aus.

📋

So funktioniert der Import:

  1. Vorlage herunterladen: Klicken Sie auf "📥 Vorlage herunterladen" um die CSV-Vorlage zu erhalten
  2. Daten eintragen: Füllen Sie die CSV-Datei mit Ihren Lagerort-Daten (Beispieldaten sind enthalten)
  3. Datei hochladen: Wählen Sie die ausgefüllte CSV-Datei und klicken Sie auf "📤 Importieren"
  4. Vorschau prüfen: Kontrollieren Sie die Vorschau und bestätigen Sie den Import
  5. Ergebnis prüfen: Nach dem Import erhalten Sie eine Zusammenfassung über erfolgreiche und fehlerhafte Einträge

Wichtige Hinweise

  • • Export-Dateien (Excel) enthalten alle Lagerorte zum Zeitpunkt des Exports
  • • Import-Vorlage (CSV) enthält Beispieldaten und Typ-Übersicht am Ende der Datei
  • • Nur CSV-Import erlaubt - Excel-Import aus Sicherheitsgründen deaktiviert
  • • Lassen Sie die ID-Spalte leer für neue Lagerorte, bestehende IDs aktualisieren vorhandene Einträge
  • • Der übergeordnete Standort muss als Name (nicht ID) angegeben werden
  • • Verwenden Sie die korrekten Typ-Bezeichnungen aus der Vorlage (z.B. "Standort/Wache", "Gebäude", "Raum")
  • • CSV-Dateien können mit Microsoft Excel, LibreOffice Calc oder Google Sheets geöffnet werden
  • • Bei Fehlern erhalten Sie eine detaillierte Fehlermeldung mit Zeilennummer
  • • Exportierte Daten regelmäßig als Backup sichern
🔧

Technische Informationen

Export-Format (Excel):

  • • Dateiformat: Excel 2007+ (.xlsx)
  • • Zeichenkodierung: UTF-8
  • • Header: Beschreibende Spaltennamen
  • • Hierarchie: Parent als Name statt ID
  • • Typ: Lesbarer Name (z.B. "Standort/Wache")

Import-Format (nur CSV):

  • • Dateiformat: CSV (.csv) - Excel aus Sicherheitsgründen nicht erlaubt
  • • Zeichenkodierung: UTF-8
  • • Pflichtfelder: name, typ
  • • Optionale Felder: parent, description, address, capacity
  • • Vorlage enthält alle verfügbaren Typen
