Was ist ein Zugriffs-Token?

Ein Zugriffs-Token ermöglicht den öffentlichen Zugriff auf ein Dashboard ohne Login. Der generierte Link kann auf beliebigen Displays (TV, Tablets, etc.) angezeigt werden.
