Benutzer-Import (CSV)

Mehrere Benutzer per CSV-Datei anlegen – inkl. Rollen und Standardpasswort.

{% if not preview %}

So funktioniert's

  • CSV mit Trennzeichen Semikolon (;). Spalten: Benutzername, Vorname, Nachname, E-Mail, Personalnummer, Benutzer-Rollen, Aktiv.
  • Benutzername ist optional – wird sonst aus Vor-/Nachname erzeugt.
  • Benutzer-Rollen kommagetrennt, exakt wie in der Rollenliste unten.
  • Ticket erstellen / Ticket bearbeiten (Ja/Nein) vergeben die gleichnamigen Einzelberechtigungen – das sind keine Rollen.
  • Neue Benutzer erhalten das Standardpasswort und müssen es beim ersten Login ändern.
