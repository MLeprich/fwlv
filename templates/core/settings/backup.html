Datensicherung

Exportieren Sie die komplette Datenbank oder importieren Sie eine Sicherung auf einem neuen System.

Administrator-Funktion

Diese Funktion ist nur für Superuser verfügbar. Backups enthalten alle Datenbank-Einträge.

Datenbank exportieren

Vollständiges Backup erstellen

Exportiert alle Daten aus der Datenbank als JSON-Datei. Diese Datei kann auf einem neuen System importiert werden, um alle Daten wiederherzustellen.

Enthaltene Daten:
✓ Benutzer & Gruppen ✓ Personal ✓ Lagerorte ✓ Kleiderkammer ✓ Magazin ✓ Medizin ✓ Ausrüstung ✓ Fahrzeuge ✓ Dokumente (Metadaten)

Hinweis: Hochgeladene Dateien (Media) sind nicht im Export enthalten. Sichern Sie den media/ Ordner separat.

Backup wiederherstellen

Laden Sie eine zuvor exportierte Backup-Datei hoch, um alle Daten auf diesem System wiederherzustellen.

Warnung: Der Import überschreibt vorhandene Daten mit denselben IDs. Führen Sie diese Aktion nur auf einem neuen/leeren System durch oder wenn Sie sich sicher sind.

Tipps zur Datensicherung

📅

Regelmäßige Backups

Erstellen Sie regelmäßig Backups, z.B. wöchentlich oder nach größeren Änderungen.

📦

Sichere Aufbewahrung

Speichern Sie Backups an einem sicheren Ort, z.B. auf einem externen Laufwerk oder in der Cloud.

🔍

Test-Wiederherstellung

Testen Sie den Import gelegentlich auf einem Testsystem, um sicherzugehen, dass das Backup funktioniert.

📁

Media-Ordner

Vergessen Sie nicht, den media/ Ordner separat zu sichern.
