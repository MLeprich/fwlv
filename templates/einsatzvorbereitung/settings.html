So kommen die Kacheln auf die Offline-Maschine

1. Auf einem Rechner mit Internet (z.B. dieser Server) das Stadtgebiet herunterladen und als ZIP verpacken:

python manage.py tiles_download --bbox {{ config.bbox|default:"51.44,6.78,51.56,6.95" }} --zoom {{ config.min_zoom }}-{{ config.max_zoom }} --zip stadt-kacheln.zip

Standardquelle ist TopPlusOpen des Bundesamts für Kartographie und Geodäsie (offene Daten, Quellenangabe „© GeoBasis-DE / BKG“). Alternativ das Luftbild von Geobasis NRW: --url "https://www.wmts.nrw.de/geobasis/wmts_nw_dop/tiles/nw_dop/EPSG_3857_16/{z}/{y}/{x}". Der öffentliche OpenStreetMap-Server sperrt Massen-Downloads und liefert nur Sperrbilder.

2. ZIP auf die Offline-Maschine kopieren (USB/Netzlaufwerk) und einspielen:

python manage.py tiles_import stadt-kacheln.zip

Im Docker-Betrieb: docker compose exec web python manage.py tiles_import /app/media/stadt-kacheln.zip – die Kacheln liegen danach dauerhaft im Media-Volume.

Größenordnung: Ein Stadtgebiet von ca. 10 × 12 km braucht bei Zoom 11–17 rund 6.000 Kacheln (≈ 60–120 MB).
