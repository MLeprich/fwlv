Daten importieren

Importieren Sie Daten aus CSV-Dateien. Laden Sie zuerst die Vorlage herunter und füllen Sie diese aus.

📋

So funktioniert der Import:

  1. Vorlage herunterladen: Klicken Sie auf "Vorlage herunterladen" für den gewünschten Datentyp
  2. Daten eintragen: Füllen Sie die CSV-Datei mit Ihren Daten (mit Excel, LibreOffice oder einem Texteditor)
  3. Datei hochladen: Wählen Sie die ausgefüllte CSV-Datei und klicken Sie auf "Importieren"
  4. Ergebnis prüfen: Nach dem Import erhalten Sie eine Zusammenfassung über erfolgreiche und fehlerhafte Einträge

Wichtige Hinweise

  • • Export-Dateien (Excel) enthalten alle aktiven Datensätze zum Zeitpunkt des Exports
  • • Import-Vorlagen (CSV) verwenden Semikolon als Trennzeichen
  • • Dateinamen enthalten Datum und Uhrzeit des Exports (Format: JJJJMMTT_HHMMSS)
  • • Excel-Dateien können mit Microsoft Excel, LibreOffice Calc oder Google Sheets geöffnet werden
  • • CSV-Dateien funktionieren mit jedem Texteditor oder Tabellenkalkulationsprogramm
  • • BTM-Daten unterliegen besonderen Sicherheitsbestimmungen - Dateien entsprechend schützen
  • • Exportierte Daten regelmäßig als Backup sichern
🔧

Technische Informationen

Export-Format (Excel):

  • • Dateiformat: Excel 2007+ (.xlsx)
  • • Zeichenkodierung: UTF-8
  • • Header: Farbcodiert nach Datentyp
  • • Datumsformat: TT.MM.JJJJ HH:MM
  • • Automatische Spaltenbreitenanpassung

Import-Format (CSV):

  • • Dateiformat: CSV (.csv)
  • • Zeichenkodierung: UTF-8 mit BOM
  • • Trennzeichen: Semikolon (;)
  • • Datumsformat: TT.MM.JJJJ
  • • Kompatibel mit Excel, LibreOffice, etc.
