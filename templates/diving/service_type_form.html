JSON-Format: Liste von benutzerdefinierten Messfeldern

Beispiel: Atemregler-Wartung

[
  {
    "name": "Ansprechdruck",
    "type": "number",
    "unit": "mbar",
    "required": true,
    "min": 15,
    "max": 30
  },
  {
    "name": "Durchflussrate",
    "type": "number",
    "unit": "l/min",
    "required": true,
    "min": 100
  },
  {
    "name": "Dichtigkeitstest bestanden",
    "type": "boolean",
    "required": true
  }
]

Feldtypen:

  • number: Zahlenwerte (mit optionalen min/max und unit)
  • text: Freitext (z.B. Bemerkungen)
  • date: Datumswerte
  • boolean: Ja/Nein (true/false)

Optionale Attribute:

  • required: Pflichtfeld (true/false)
  • min/max: Minimal-/Maximalwert für Zahlen
  • unit: Einheit (z.B. "mbar", "l/min", "°C")
  • placeholder: Platzhaltertext
  • help_text: Hilfetext für das Feld
