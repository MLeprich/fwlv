Wichtige Hinweise

  • • Export: Daten werden als Excel-Datei (.xlsx) mit Formatierung exportiert
  • • Import: Excel-Dateien (.xlsx, .xls) werden akzeptiert
  • • Excel-Dateien sollten UTF-8 codiert sein
  • • Laden Sie immer zuerst die Vorlage herunter, um das richtige Format zu sehen
  • • Pflichtfelder sind mit * markiert
  • • Duplikate werden automatisch erkannt und übersprungen
  • • Nach dem Import erhalten Sie eine Zusammenfassung mit Erfolgen und Fehlern
  • • Datum-Format: TT.MM.JJJJ (z.B. 31.12.2024)

⚙️ Technische Informationen

Export-Format:

  • • Dateiformat: Excel (.xlsx)
  • • Zeichenkodierung: UTF-8
  • • Formatierung: Farbige Header, Spaltenbreiten
  • • Datum-Format: TT.MM.JJJJ

Import-Format:

  • • Dateiformat: Excel (.xlsx, .xls)
  • • Zeichenkodierung: UTF-8
  • • Header-Zeile muss vorhanden sein
  • • Leere Zeilen werden ignoriert
