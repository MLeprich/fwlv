📥 CSV-Import

Kategorien und Items in die Vorlage {{ template.name }} importieren. Bereits vorhandene Items (gleicher Name in gleicher Kategorie) werden übersprungen.

Format (Trennzeichen ;, UTF-8):

Kategorie; Kategorie-Beschreibung; Kategorie-Prüfintervall; Item; Item-Beschreibung; Seriennummer erforderlich; Foto möglich; Prüfintervall; Erwartete Anzahl

  • Eine Zeile mit Kategorie, aber ohne Item, legt nur die Kategorie an.
  • „Seriennummer erforderlich" / „Foto möglich": Ja / Nein.
  • Prüfintervall: täglich / wöchentlich / monatlich / keine (Item leer = von Kategorie erben).
  • Gleiche Kategorie-Namen werden zusammengeführt.
